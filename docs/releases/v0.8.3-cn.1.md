## Synara v0.8.3 可选语言社区版

本版从原来的固定中文界面升级为**用户可以自己选择语言**的版本，基于 [上游稳定版 v0.8.3](https://github.com/Emanuele-web04/synara/releases/tag/v0.8.3)。这是非官方 Windows x64 社区构建，不是上游官方发布。

**[下载安装包](https://github.com/panda4556/synara/releases/download/v0.8.3-cn.1/Synara-0.8.3-cn.1-x64.exe)** · **[中文安装说明](https://github.com/panda4556/synara/releases/download/v0.8.3-cn.1/README.zh-CN.md)** · **[SHA-256 校验文件](https://github.com/panda4556/synara/releases/download/v0.8.3-cn.1/SHA256SUMS.txt)**

### 新增：自行选择语言

- 在 **设置 → 常规 → Language / 语言** 中选择 **跟随系统 / System default、English、简体中文**。
- 切换立即生效，无需重启。选择保存在本地，正常情况下刷新或重启后保留，同一来源的多个窗口同步。
- 默认跟随系统/浏览器的首选语言；简体中文使用中文，其他未支持语言回退英文。
- 支持在设置搜索中输入 `Language`、`English`、`中文`、`语言` 或 `跟随系统`。
- 全局“恢复默认设置”会将语言恢复为跟随系统。
- 切回英文会停用兼容翻译层并恢复原文；不改写聊天正文、代码、终端输出或用户输入。

![语言选择界面](https://github.com/panda4556/synara/releases/download/v0.8.3-cn.1/language-selector.png)

### 同步上游 v0.8.3

- 修复打包应用缺少 `zod`，可能导致部分 ACP 服务商启动失败的问题。此类问题需要升级应用，在项目中单独安装 `zod` 不能修复应用包。
- 记住 Split / Stacked Diff 布局，在面板重建和应用重启后保留。
- 增强打包运行时依赖验证，移除未使用的 CommonJS 服务端产物。

以上修复来自上游，详见 [官方更新记录](https://github.com/Emanuele-web04/synara/releases/tag/v0.8.3)。

### 安装与升级

1. 下载 `Synara-0.8.3-cn.1-x64.exe`；`Source code` 是源码，不是安装程序。
2. 保存工作、正常退出 Synara，并备份自己的数据与配置。默认位置为 `%USERPROFILE%\.synara` 和 `%APPDATA%\synara`；如使用自定义数据目录，也要备份。
3. 校验文件后运行安装包，沿用原安装位置，重新打开 Synara。
4. 到 **设置 → 常规 → Language / 语言** 选择语言。Windows 文件属性可能显示 `0.8.3.0`，对应社区安装包版本 `0.8.3-cn.1`。

已验证 Windows 本机从 `0.8.1-cn.1` 覆盖升级后能够启动、打开原有对话和选择语言。升级可能执行上游数据迁移；如需回退，请保留当前数据并恢复升级前匹配的备份，不要直接让旧版打开已迁移的数据。备份可能含登录信息，请勿公开上传。

### 已知限制与更新方式

- **未签名的社区构建**：Windows 可能提示未知发布者或 SmartScreen。请核对来源与 SHA-256；校验值不代替代码签名或安全审计。
- 仅发布 Windows x64。语言入口是原生设置，但已有界面的中文仍复用可选的兼容翻译层，尚非全量原生 i18n；部分文案和系统界面可能仍是英文。
- 不改变服务商登录、模型调用、额度或计费方式。
- 设置页上游顶栏可能遮挡全局“恢复默认设置”按钮的一部分，键盘 Tab 聚焦后可操作；语言下拉框不受影响。
- **不启用自动更新**，后续请从本 fork 的 Releases 手动更新。本 Release 的 `Latest` 仅指本 fork 推荐下载版本，不代表启用了应用内自动升级。
- 旧版 `v0.8.1-cn.1` 安装包与标签保留。

### English summary

Unofficial, unsigned Windows x64 build based on Synara v0.8.3. Select **System default / English / Simplified Chinese** in **Settings → General → Language / 语言**. Switching is immediate and preferences are saved locally. Conversation text, code, and terminal output are not translated. Includes the upstream v0.8.3 packaged `zod` fix and diff-layout persistence. Manual updates only; existing UI translations still use an optional compatibility layer. Checksums and source provenance are attached. Only Windows x64 has been packaged and verified.
